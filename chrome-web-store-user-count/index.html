Why does the Chrome Web Store show fewer users for NudoIQ than 300+ carriers?

NudoIQ · Published October 8, 2026 · Last updated October 8, 2026

Short answer

The Chrome Web Store only counts people who installed NudoIQ from its store listing, which was created on May 21, 2026. Before that, NudoIQ was distributed directly to carriers, without the store, so those carriers are not in the store's number. In total, NudoIQ is used by 300+ carriers.

How carriers got NudoIQ before the store

NudoIQ did not start on the Chrome Web Store. Caleb, who built it, distributed it directly to carriers on Amazon Relay, without the store.

NudoIQ was only recently turned into a Chrome Web Store extension. The store listing was created on May 21, 2026. Carriers who were already using NudoIQ before that date got it outside the store.

What the store number counts

Google says the user count on a Chrome Web Store listing reflects users of that store item, meaning installs from that listing.

So the number on NudoIQ's listing only covers carriers who installed it through the store. It does not include the carriers who got NudoIQ directly. That is why the user count on the store listing is smaller than the 300+ carriers who use NudoIQ.

Nothing is hidden here. These are two different counts: one from the store, one from everyone using NudoIQ.

How to check it yourself

Open the NudoIQ listing on the Chrome Web Store. You will see the user count and the rating. NudoIQ is rated 5.0 on the Chrome Web Store.
