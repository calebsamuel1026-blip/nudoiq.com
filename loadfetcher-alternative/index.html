What is Load Fetcher?

LoadFetcher is a Chrome extension for Amazon Relay, published by Fierce Trade LLC (checked October 14, 2026). NudoIQ is a separate one, with AutoBook at your minimum net profit.

Is Load Fetcher a Chrome extension?

Yes, it installs from the Chrome Web Store. NudoIQ is a separate Chrome extension. If you try both, run one load board extension at a time so they don't clash.
